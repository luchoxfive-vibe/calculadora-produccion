# Calculadora de proyectos

Estimador de costo y tiempo para proyectos de imprenta y gráfica. Compara presupuestos públicos de proveedores de Córdoba y Argentina y recomienda la opción más barata, la más rápida o la equilibrada.

- Precios públicos consultados el 07/10/2026 (IVA incluido salvo aclaración).
- Los precios sin fuente pública son referencias estimadas y llevan un recargo del 20% si tienen más de 6 meses.
- Valores orientativos para negociar; no son cotizaciones.
